# 推焦推演台（焦化厂值班工长用）

纯本地网页，无需联网、无需安装：双击 `index.html` 用浏览器（Chrome/Edge）打开即可，
可直接拷到值班电脑。条件保存在浏览器本地（localStorage），刷新不丢。

## 怎么用
- 左侧接班条件：日期、接班时刻、炭化室孔数、推焦串序（2-1 / 5-2 / 9-2）、
  首推炉号、首孔计划推焦、结焦时间、允许提前/滞后分钟、相邻序号计划间隔。
- 三车：推焦车（一台）、拦焦车、熄焦车各自的走行速度（分/孔）、单孔占时/周转、
  接班轨位，以及“故障停用至”（模拟某台车不到位）。
- 检修计划：任意插入封锁时段（可跨日），时段内所有孔自动让路。
- 任意条件一改，整表即时重算；也可点“立即重算”。
- 明细表中直接改某孔“计划推焦”，该孔及其后所有序号整串平移重排。
- 顶部时序图上按住鼠标左右拖，就是“拨时刻”；右上有播放、+10 分钟、一键拨到 10:00。
- 点图上的圆点或表中行，右侧单孔回溯会翻出：装煤时刻、结焦、计划窗口、
  三车分别几点到、等没等窗口、检修让到几点、被上一序号压了多少、最终偏差，
  以及拨杆时刻“前面还压着几孔、具体是哪几孔”。

## 颜色含义
- 绿点：窗口内准点；黄点：车齐了但结焦没到，等窗口（防止生焦）；
  橙点：被车/检修顺延，但仍在窗口内；红色菱形：已过窗口判废，不再向后排。
- 紫色竖带：检修封锁。时序图右半压暗区 = 拨杆时刻之后（尚未发生）。

## 推演口径（与现场一致）
对串序中的每一孔：窗口 = [计划推焦−允许提前, 计划推焦+允许滞后]。
三车各自“上孔释放时刻 + 到本孔走行分钟”取最慢者为最早可动时刻；
撞检修段顺延到检修结束；早于窗口起点必须等到窗口开（早了出生焦）；
晚于窗口终点即判生焦/废炉，该孔停排且不移动车，后续序号依次顶替。
判废孔在时间序上仍占号位（车最早要到其窗口关闭后才能继续），因此连锁顺延成立。

## 自检
- `node test-engine.js`：24 条引擎规则断言（串序、窗口、三车、检修、连锁、判废等）。
- `node test-ui.js`：无头浏览器冒烟测试（渲染、改条件重算、拨杆、单孔回溯）。
